经销商管理套表 GitHub Pages 发布包

用途：
- 上传到 GitHub 仓库后，可以通过 GitHub Pages 链接分享查看。
- 当前业务数据已随包放在 dealer-management.json。

推荐上传方式：
1. 登录 GitHub，新建一个公开仓库，例如 dealer-management-dashboard。
2. 把本文件夹内所有文件上传到仓库根目录。
3. 打开仓库 Settings > Pages。
4. Source 选择 Deploy from a branch。
5. Branch 选择 main，目录选择 /root，保存。
6. 等待 1-3 分钟，GitHub 会生成访问链接。

注意：
- 这是分享查看版。别人打开后能看到当前随包数据。
- 别人在网页里修改的数据只保存在他自己的浏览器，不会写回你的 E 盘。
- 你以后本机数据更新后，需要重新生成/上传发布包，分享链接才会显示新数据。
